# 经典图谱 · Classical Atlas

> 以《周易》为骨干、各家经典为连线之星的中国系统思维学习平台。

一个学习中国传统经典的网站。**核心立意**：《易经》是中国系统思维理论的结晶，作为骨干；道（《道德经》《常清静经》）、儒（阳明心学）、佛（《心经》）各家以「关联网络」与之相系，未来向西方经典辐射。

本仓库实现的是经 [Claude Design](https://claude.ai/design) 迭代定稿的**交互原型「经典图谱」**：星图首页（关联网络）+ 经卷长轴阅读（沉浸阅读）的混搭，外加八八卦阵、六维立体图、卦变与卦族。

## 设计系统（极简留白 · 当代东方）

- **配色**：暖白 `#f7f6f4` + 浓墨 `#1b1b19` + 青瓷绿 `#3a5f5a`（唯一主强调）+ 朱砂 `#9c3a2f`（仅用于印章/动爻）。深色主题成套切换。
- **字体**：标题书法 `Ma Shan Zheng` + 正文宋体 `Noto Serif SC`（可切黑/楷）+ 等宽 `Space Mono` 作「二进制/系统」标签。
- **母题**：阴阳爻（实线=阳、断线=阴）以 `div` 拼搭，呼应二进制/系统逻辑。
- **Tweaks**（右下角）：正文字体 宋/黑/楷、深色模式、主色四选（青瓷/黛蓝/陶/橄榄），本地持久化。

## 画面（单页 React SPA · 1440×900 舞台缩放）

| 画面 | 说明 |
|---|---|
| **星图首页** | 《易经》为最亮核心节点（脉冲），道/儒/佛/常清静经 + 西方经典(幽灵)环绕，连线带关系标签；悬停高亮、点击进入。 |
| **经卷长轴 · 乾卦** | 左骨干六爻**可逐爻点击**切换爻辞 + 卦族(错/综/互/交) + 卦变；右象/彖/爻辞/白话/注解占位 + 辐射各家 chips。 |
| **经卷长轴 · 道德经** | 左章目录、右第一章逐句排布，每句带注占位，底部一枚按钮回《易》。其余各家为「即将上线」占位。 |
| **六十四卦方阵** | 8×8（上卦×下卦），可按卦名/卦序/八卦实时搜索高亮，点格进入单卦页。 |
| **卦象立体图** | 64 卦 = 六维超立方体；「立方套立方 / 同心环」两投影；选中点亮 6 条邻边（单爻之变）+ 错卦对角连线。 |
| **单卦页** | 任意卦的卦象、上/下卦分解、卦族、卦变推演（经文编撰中）。 |

转场用 `view-enter` 动画，`Esc`/「‹ 星图」返回，当前画面 `localStorage` 记忆。

## 技术栈

- [Astro](https://astro.build) 5 + [@astrojs/react](https://docs.astro.build/en/guides/integrations-guide/react/)（整套原型为一个 `client:load` React island，SSR 首屏 + 客户端交互）
- 无后端、无数据库：经典内容与卦表为类型化数据模块

## 开发

```bash
pnpm install
pnpm dev        # http://localhost:4321
pnpm build      # 构建到 dist/（GITHUB_PAGES=true 时走 /classic_system 子路径）
pnpm check      # Astro + TypeScript 类型检查
pnpm verify     # 结构自检（八卦/64卦模式互异、错/综/交对合、互卦点验）
```

## 目录结构

```
src/
├─ components/atlas/
│  ├─ data.ts         # 八卦、真实经文、各家经典、星图节点
│  ├─ hex.ts          # 64卦名表、由爻查卦、卦变(之卦)、卦族(错/综/互/交)、爻位名
│  ├─ primitives.tsx  # 阴阳爻 / 卦象 / 动爻形变
│  ├─ chrome.tsx      # wordmark / mono 标签 / 印章
│  ├─ shared.tsx      # 顶栏 / 占位槽 / 辐射 chips / 卦变面板 / 卦族面板
│  ├─ StarMap.tsx     # 星图首页
│  ├─ Reading.tsx     # 经卷长轴（乾卦 / 道德经 / 占位）
│  ├─ Matrix.tsx      # 八八卦阵 + 单卦页
│  ├─ Cube.tsx        # 六维立体图
│  ├─ Tweaks.tsx      # 字体/深色/主色控件
│  └─ App.tsx         # 外壳：舞台缩放、路由、转场、主题
├─ pages/index.astro  # 挂载 <App client:load>
└─ styles/global.css  # 设计令牌 + 深色主题 + 关键帧
```

爻一律「自上而下」存储（index 0 = 上爻），与渲染叠放一致。

## 路线图

1. **（已上线）原型骨架**：星图、乾卦/道德经阅读、卦阵、立体图、卦变、卦族、Tweaks。
2. **内容做厚**：64 卦卦爻辞按可靠底本逐卦录入；《道德经》补章、《心经》《常清静经》《阳明心学》做成完整可读。
3. **连接层**：星图连线背后的「概念图谱」——各家核心概念按对应/阐发/对比/源流挂到易经系统思维原语上。
4. **工程化**：接入完整经文库、全文搜索、登录/收藏/学习进度（开发交接）。
5. **向西辐射**：系统论 / 控制论 / 辩证法等西方经典经同一图谱接入。
