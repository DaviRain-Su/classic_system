# 观象 · 易经系统思维学习平台

> 以《周易》为骨干，习中国之系统思维。骨干立，则道、儒、佛诸家为四肢，渐次辐辏。

一个学习中国传统经典的网站。**核心立意**：真正的「骨干」不是《周易》这本书的文字，而是从易经里抽象出的那套**系统思维原语**（阴阳、变易、对待与流行、时位、中正、象数理）。理解了它们，道家的「无为」、儒家的「中庸」、佛家的「无常」便能各自挂接到同一套坐标上——这才是「四肢结合」得以成立的根基。

## 技术栈

- [Astro](https://astro.build) 5（内容优先，静态导出）
- MDX（长文 / 方法论）+ React island（起卦等交互）
- 无运行时数据库：经典内容以类型化数据 + MDX 维护

## 开发

```bash
pnpm install
pnpm dev        # 本地开发 http://localhost:4321
pnpm build      # 构建到 dist/
pnpm check      # Astro + TypeScript 类型检查
pnpm verify     # 引擎自检（64 卦 / 错综互卦数学性质）
```

## 已实现（第一阶段：夯实易经主干）

- **六十四卦**：全部结构由八卦二进制**程序推导**——六爻、上下卦、错卦 / 综卦 / 互卦关系零手抄误差。
- **可视化**：
  - 单卦六爻 SVG（`GuaSymbol`），支持动爻标记与爻位高亮；
  - 六十四卦「上卦 × 下卦」8×8 方阵——系统状态空间的全貌；
  - 起卦 → 本卦 / 动爻 / 之卦的卦变演示。
- **起卦**：三枚铜钱法，含老阴老阳变爻、本卦与之卦联动。
- **经文**：乾、坤两卦做满（卦辞 / 彖 / 大象 / 爻辞 / 用九用六 / 系统思维导读）作为内容模板；其余 62 卦先上结构与卦变关系，经文位明确标注「待校订录入」，**不臆造**。
- **八卦**：象、德、家庭、方位、取象口诀。
- **系统思维**：六原语导论（`/fangfa`）。

## 目录结构

```
src/
├─ data/
│  ├─ trigrams.ts         # 八卦定义（仅最小事实）
│  ├─ hexagrams.raw.ts    # 64 卦原始数据（序号/卦名/上下卦）
│  └─ hexagram-text.ts    # 卦爻经文（已校订者）
├─ lib/
│  ├─ iching.ts           # 引擎：二进制推导、错综互卦、爻题、查询
│  └─ cast.ts             # 起卦逻辑（三枚铜钱）
├─ components/
│  ├─ GuaSymbol.astro     # 卦象 SVG
│  └─ CastingTool.tsx     # 起卦交互（React island）
├─ layouts/Base.astro
└─ pages/
   ├─ index.astro         # 首页（立意 + 入口 + 六原语）
   ├─ gua/index.astro     # 六十四卦总览（方阵 + 序卦）
   ├─ gua/[id].astro      # 单卦详情（× 64）
   ├─ bagua/index.astro   # 八卦
   ├─ cast.astro          # 起卦
   └─ fangfa.mdx          # 系统思维方法论
scripts/verify.ts          # 引擎自检
```

### 设计要点：事实最小化，结构程序化

`data/` 只记录「无法推导的最小事实」（卦名、上下卦）。一切可推导之物（六爻、二进制、错综互卦）都由 `lib/iching.ts` 在加载时计算。好处：数据不会自相矛盾，新增 / 校订成本低，且 `pnpm verify` 可对推导结果做数学性质断言（对合性、自综卦集合等）。

## 路线图

1. **（进行中）易经主干**：结构 ✓、可视化 ✓、起卦 ✓；经文逐卦校订录入（依阮元《十三经注疏》本等可靠底本）。
2. **四肢接入**：《道德经》《常清静经》《心经》、阳明心学。沿用统一经典数据模型（原文 / 注 / 译 / 历代注疏 / 现代解读）。
3. **连接层**：建立「概念图谱」——以易经系统思维原语为枢纽节点，把各家核心概念（无为、中庸、无常、空…）按「对应 / 阐发 / 对比 / 源流」挂接其上。这是「四肢结合」的技术实现。
4. **学习闭环**：学习路径、笔记 / 心得、卦象记忆与概念测验。
5. **向西辐射**：系统论、控制论、复杂系统、辩证法等西方经典经由同一图谱接入。
